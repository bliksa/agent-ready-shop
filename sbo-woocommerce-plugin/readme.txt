Make your WooCommerce store readable and buyable for AI agents like ChatGPT, Claude, and Gemini.

== Description ==

As commerce moves from search engines (SEO) to AI agents (AIO), traditional websites are becoming invisible to machines. SBO (Shopping Bot Optimization) bridges this gap.

This free version automatically generates and exposes a highly optimized `/llms.txt` file at the root of your WordPress installation, summarizing your store's configuration, shipping policies, and product catalog links directly to LLMs.

PRO Version includes WebMCP transaction protocols, allowing AI to autonomously load your products into carts and fetch accurate shipping prices in real-time.

== Installation ==

1. Upload the `sbo-woocommerce` directory to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Visit the 'SBO Plugin' menu to view your active llms.txt file status.
